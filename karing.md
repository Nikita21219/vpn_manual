# Karing (iOS / iPadOS)

## Шаг 1. Скачайте приложение

[Скачать Karing из App Store](https://apps.apple.com/app/id6472431552)

## Шаг 2. Добавьте профиль

Скопируйте ключ, который я отправил.

1. Нажмите **Добавить профиль**
2. Выберите **Добавление подписки**
3. Вставьте ключ в поле **Ссылка на подписку/содержание**
4. Нажмите **галочку** в правом верхнем углу

<img src="images/karing1.png" width="700">

## Шаг 3. Подключитесь

Нажмите круглую кнопку внизу экрана. При первом подключении разрешите добавить VPN-конфигурацию. Кнопка стала зелёной - VPN работает.

<img src="images/karing2.png" width="400">

## Важно

Не выбирайте ключи с пометкой **Аварийный**. Используйте их только в случае, если не работает ни один из обычных ключей.
