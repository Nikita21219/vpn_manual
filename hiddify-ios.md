# Hiddify (iOS / iPadOS)

Альтернативное приложение. Основная инструкция для iOS - [Clash Mi](ios.md).

> Hiddify доступен не во всех регионах App Store. Если приложение не находится - используйте [Clash Mi](ios.md), [Karing](karing.md) или [INCY](incy.md), либо [смените регион App Store](app-store-region.md).

## Шаг 1. Скачайте приложение

[Скачать Hiddify из App Store](https://apps.apple.com/us/app/hiddify-proxy-vpn/id6596777532)

## Шаг 2. Добавьте профиль

1. Скопируйте ключ, который я отправил
2. Внизу экрана откройте вкладку **Профили**

<img src="images/hiddify1.png" width="400">

3. Нажмите **+** в правом верхнем углу

<img src="images/hiddify2.png" width="400">

4. Выберите **Добавить из буфера обмена**

<img src="images/hiddify3.png" width="400">

## Шаг 3. Подключитесь

1. Вернитесь на вкладку **Главная** внизу слева
2. Нажмите большую круглую кнопку подключения в центре экрана
3. При первом подключении разрешите приложению добавить VPN-конфигурацию в настройки iPhone

<img src="images/hiddify4.png" width="400">

## Важно

Не выбирайте ключи с пометкой **Аварийный**. Используйте их только в случае, если не работает ни один из обычных ключей.
