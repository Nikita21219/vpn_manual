# 🍎 iOS / iPadOS

Основное приложение - **Clash Mi**.

## Шаг 1. Скачайте приложение

[Скачать Clash Mi из App Store](https://apps.apple.com/ru/app/clash-mi/id6744321968)

## Шаг 2. Добавьте профиль

Скопируйте ключ, который я отправил, и откройте Clash Mi:

1. Нажмите на кнопку **+** рядом с пунктом **Профили**
2. Выберите **Добавление подписки**
3. Вставьте ключ в поле **Ссылка на профиль Clash**
4. Нажмите галочку в правом верхнем углу

<img src="images/ios1.png" width="700">

## Шаг 3. Подключитесь

Включите переключатель в верхней части экрана.

<img src="images/ios2.png" width="350">

## Важно

Не выбирайте ключи с пометкой **Аварийный**. Используйте их только в случае, если не работает ни один из обычных ключей.
