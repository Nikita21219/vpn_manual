# iOS/iPadOS (INCY)

## Шаг 1. Скачайте приложение

[Скачать INCY из App Store](https://apps.apple.com/ru/app/incy/id6756943388)

## Шаг 2. Добавьте профиль

1. Скопируйте ключ, который я отправил
2. Откройте INCY и нажмите кнопку **Вставить**, чтобы импортировать конфигурацию
3. Разрешите приложению вставку из буфера обмена

## Шаг 3. Подключитесь

1. Выберите нужную локацию из списка серверов
2. Запустите подключение
3. При первом подключении разрешите приложению добавить VPN-конфигурацию в настройки iPhone

## Важно

Не выбирайте ключи с пометкой **Аварийный**. Используйте их только в случае, если не работает ни один из обычных ключей.
