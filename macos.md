# 🍏 macOS

Основное приложение - **Hiddify**.

## Шаг 1. Скачайте и установите приложение

[Скачать Hiddify](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-MacOS.dmg)

1. Откройте скачанный `.dmg` и перетащите **Hiddify** в папку **Applications**
2. При первом запуске macOS заблокирует приложение - нажмите **Готово**
3. Откройте **Системные настройки → Конфиденциальность и безопасность** и разрешите запуск Hiddify
4. Запустите приложение ещё раз и нажмите **Все равно открыть**

## Шаг 2. Добавьте профиль

1. Скопируйте ключ, который я отправил
2. Откройте вкладку **Профили**

<img src="images/hiddify1.png" width="400">

3. Нажмите **+** в правом верхнем углу

<img src="images/hiddify2.png" width="400">

4. Выберите **Добавить из буфера обмена**

<img src="images/hiddify3.png" width="400">

## Шаг 3. Подключитесь

1. Вернитесь на вкладку **Главная**
2. Нажмите большую круглую кнопку подключения в центре экрана
3. При первом подключении разрешите добавить VPN-конфигурацию в системные настройки

<img src="images/hiddify4.png" width="400">

## Важно

Не выбирайте ключи с пометкой **Аварийный**. Используйте их только в случае, если не работает ни один из обычных ключей.
